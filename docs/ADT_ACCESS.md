# ADT Access

## Rule

ADT is licensed data. There is no legal workaround for the licence.

Do not download ADT data until the licence is approved.

## Steps

1. Open the official Aria Digital Twin documentation.
2. Find the dataset request or licence page.
3. Use your university email and project account.
4. State the research use: causal map maintenance and 4D mapping.
5. Accept the terms with the project account.
6. Request the temporary download-link file.
7. Put the link file on the cluster only.
8. Do not commit the link file or send it in chat.

## If the Licence Is Not Approved

Use this order:

1. Build and test the full system on synthetic data.
2. Record a controlled room capture with a phone.
3. Use the controlled capture for the public demo.
4. Report the synthetic and controlled results with clear limits.
5. Run ADT later when the licence is approved.

Do not use unofficial mirrors.

Do not present synthetic results as ADT results.

## Alternative Data

Other egocentric datasets also have licences or access forms. They do not remove
the need for a data agreement. Use them only after you read the terms.
